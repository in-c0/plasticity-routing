\begin{abstract}
Continual agents are usually given a fixed pathway along which experience is
committed to memory. We ask whether an agent can instead \emph{learn} which
substrate a new experience should change, from delayed future task utility,
under interference and storage/compute constraints. We formalise this as a
resource-aware write-depth allocation problem over four actions
(\textsc{ignore}, \textsc{episodic}, \textsc{fast}, \textsc{slow}), introduce a
synthetic benchmark in which the optimal depth differs by hidden class and is
unobservable at decision time, and evaluate a learned policy against
depth-agnostic controls, a fixed heuristic, a budget-matched random control, and
a class-conditional oracle upper bound derived by exhaustive search.

\section{Introduction}

Our contribution is deliberately narrow. We do \emph{not} claim that routing to
experts is new \cite{shazeer2017moe,fedus2021switch,zhou2025twolevel}, that
using multiple memory systems is new
\cite{behrouz2024titans,pattichis2026multitimescale,lampinen2025latent}, or that
deciding whether to write to memory is new
\cite{yan2025memoryr1,simsek2026forget,hu2026memrouter}. The question we isolate
is whether a policy can learn a \emph{resource-aware write-depth} policy from
future utility, and whether any gain is attributable to routing rather than to
capacity, compute, or privileged task identity.

\paragraph{Prior.} Our prior on a positive result is low. Yoon
\cite{yoon2026subspace} reports that a simple similarity rule matches or beats a
learned reinforcement-learning allocation controller under fixed capacity. We
therefore treat a fixed heuristic as the primary comparator and preregister a
negative replication as a publishable outcome.

\section{Problem formulation}

At each write event $t$ the agent observes $(k_t, v_t)$ and selects an action
$a_t \in \{\textsc{ignore}, \textsc{episodic}, \textsc{fast}, \textsc{slow}\}$
from a policy $\pi_\theta(a \mid \phi_t)$, where $\phi_t$ is a feature vector
that is a function of the stream prefix only. The objective is
\begin{equation}
J = U - \lambda_f F - \lambda_s S - \lambda_w W - \lambda_c C,
\end{equation}
with $U$ mean per-query recall utility, $F$ retention regression measured by
evaluator-only probes, and $S, W, C$ normalised storage, write, and compute
consumption under a cost table and hard write ceiling shared by every arm.

\section{Negative and null results}

Development-stage findings preserved regardless of the final outcome:
\begin{enumerate}
  \item an assumed class-to-action mapping presented as an oracle was not an
        upper bound and was beaten by the fixed heuristic;
  \item the designed mapping was falsified by exhaustive search;
  \item arrival time leaked the hidden class, caught by the first-encounter
        independence test on an untrained policy;
  \item an episodic cost model omitting key storage and search cost let a
        capacity-matched exact store beat the oracle;
  \item per-decision policy-gradient credit assignment could not see most of the
        objective and did not train.
\end{enumerate}

\section{Limitations}
